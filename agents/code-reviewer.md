# Code Reviewer Agent

A specialized agent for performing thorough code reviews.

## Capabilities

- Identifies potential bugs and security vulnerabilities
- Suggests improvements for code readability
- Checks for adherence to best practices
- Provides constructive feedback

## Usage

Invoke this agent when you need a second pair of eyes on your code changes.
